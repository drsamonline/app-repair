Right-to-repair guides and part sources for your appliance — for your exact model, with a verdict on every guide.

Open Repair

A mains-powered appliance marked not a home repair is not a challenge; it is a warning. The app does not diagnose a fault it cannot see, and a guide for a neighbouring model is a guide for a different machine.

Status Built and working: model search that matches exactly and names a neighbouring model as a near miss rather than offering its guides; symptom search that returns guides across models and names each one; a three-verdict scale on every guide; mains appliances marked not a home repair with the reason and no steps; and parts listed against a model, never a family.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: a full guide library. The set is five appliances and ten guides — a demonstration of the structure, and every guide says what it is.

The three verdicts

VerdictWhat it means
home repairYou can do this with ordinary tools.
carefulDoable, but a step will ruin it if you rush.
not a home repairMains, sealed or gas. Do not open it — and the guide offers no steps.

What it does

  • Finds the guides for one exact model, and the parts for that model.
  • Names a neighbouring model as a near miss instead of lending you its guide.
  • Searches by symptom across models, naming the model each guide belongs to.
  • Marks every guide with one of three verdicts, and gives the reason on a mains appliance.

What it will not do

  • Diagnose a fault it cannot see. No symptom guessing, no "probably the capacitor".
  • Encourage you into a mains appliance. Those guides have a reason and no steps.
  • Return a neighbour's guide as though it were the same.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputAn empty model or symptom search is refused with the field named.
No matchA model with no guide is refused, with any neighbouring models named; an unmatched symptom is refused and no fault is guessed.
No networkNothing changes; the guide set is bundled.
Corrupt saved stateReported and offered for export; never replaced with an empty list.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
